## GIFT for Visual Place Recognition

[GIFT: A Generative Imagined Fine-Tuning Framework for Visual Place Recognition](https://github.com/kuzhengyu/GIFT) (ICASSP 2026) investigates generative fine-tuning for visual place recognition under changing environmental conditions.

The official repository provides the synthesized image dataset used in the paper: approximately 140,000 images generated from three GSV-Cities source cities under six conditions, including snow, fog, sun, night, rain, and overcast. The resource is designed to work with established VPR pipelines.
